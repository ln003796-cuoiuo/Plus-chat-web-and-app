# PlusChat Android

Это форк Telegram Android с измененным брендингом и серверами.

## Изменения:
- Переименовано в **PlusChat**
- Серверы заменены на `прото.плюсчат.рф` (IP: 195.3.246.75)
- Удалены проблемные генераторы схемы TLRPC
- Обновлен workflow для GitHub Actions

## Сборка:
APK собирается автоматически через GitHub Actions при каждом пуше в ветку `main` или `master`.

## Структура:
- `.github/workflows/build.yml` — конфигурация сборки
- `TMessagesProj/` — основной исходный код приложения
- `gradle/` — настройки Gradle

## Лицензия:
Оригинальный проект Telegram распространяется под лицензией GPL v2. Данный форк наследует эту лицензию.
